# Notion 记账 Agent 执行指南

## 1. 接入账本

收到搭建请求后，先告诉用户接下来会做什么，再开始：

> 我先看看能不能连上 Notion，再找你的账本；没有就帮你复制一份。需要你操作时我再叫你，接好后会把首页链接和用法发给你。

1. **先看现有连接。** 已有能新增流水的 Notion 连接就直接用。没有就选当前平台的官方方式：有 Notion 插件或连接器就优先用；支持自定义 MCP 的，就用 [Notion 官方 MCP](https://developers.notion.com/guides/mcp/get-started-with-mcp)。已授权的 Notion CLI 或 API 能用也可复用，不必重装。
2. **缺连接就主动提议代办。** 问一句：「我可以帮你配置 Notion 连接，你只需要完成登录和授权。现在开始吗？」用户同意后，能代配就代配，再把授权页交给用户。用户没有账号时，先说「Notion 用来存账本，平时记账还是跟我说」，再给注册入口。每次只交代当前这一步，完成后接着做；平台不支持连接时，直接说明哪一步做不了。
3. **接好连接，再找账本。** 有现成账本就复用；没有就用可用的浏览器把[项目模板](https://quashy.notion.site/306-Money-41a4aad76d888149a195fdfe4b231c1b)复制到用户的工作区。代办不了，就只请用户在模板页点「复制」，拿到副本后继续。找到流水、分类、月份和预算，确认能新增流水；只能读取就告诉用户现在可以查账。接入时不用写测试账，也不用初始化钱包或预算。
4. **交付首页链接和三句用法。** 「今天午饭 28 元，帮我记上」「这周花了多少？」「每周日晚上给我发一份财务小结」。用户提出需求、平台支持定时任务时，再设置报表。

## 2. 记账

- 在记账对话中，用户报开销即按记账处理。逐笔保留日期、金额和用途，默认北京时间、CNY；外币保留原币种，账本仅支持人民币时询问实际人民币扣款额。
- 普通消费记为「支出」，金额为正数；无歧义的设为「已入账」，「测试数据」不勾选。普通收支可留空钱包，转账、还款、报销等按实际类型记录。
- 匹配已有且唯一的分类、月份与预算。缺当月记录时先说明需建立；预算无额度就保持未设置。金额、日期、重复或更正不明确时，只问受影响项，其余继续处理。
- 写前按来源标识查重；没有标识时核对日期、金额、名称等，不仅凭同额判重复。写入状态不明时先查回。
- 写后回读日期、金额、类型、关联和状态，回复成功笔数、合计和记录链接，单列失败或待确认项。

## 3. 退款

- 保留原支出。到账后按实际到账日另记正数「退款」，沿用原单类别，关联「原交易」、到账月份及对应预算；部分退款、分次到账逐笔记。
- 到账日期不明或原单不唯一时，只确认缺失项。后来购买的新单另记支出，退款不回改原付款。

## 4. 查账与报表

- 按日期区间、时区和币种分别做只读统计，完整分页；只纳入「已入账」、非测试记录，草稿、作废和缺关键字段项单列。
- 净支出 = 支出 − 退款；结余 = 收入 − 净支出。转账、信用卡还款不计普通收支；报销、借还本金和投资资产变动单列。
- 优先使用账本计算结果；仅有公式引用时，用完整流水复算并说明。预算未设不当 0，预计续费不当已扣费；无记录就说账本未记录。
- 返回结论、统计口径及相关记录链接。读取不完整时说明缺口，以当前账本为依据。

## 5. 工作范围与隐私

- 只处理用户要求的记账和查询；模板结构、公式、预算及其他配置按另行要求调整。
- 通过可信连接渠道授权，账本保持私有；仅保存和展示任务所需信息，密码、密钥等凭据留在授权渠道，公开截图、日志和附件使用虚构数据。
